# Восстановление изображений после сжатия x265

Лабораторная работа по теории информации. Цель — повысить средний покадровый RGB PSNR на 100 тестовых кадрах минимум на **0,100 дБ** относительно базовой QECNN.

| Вариант | Средний RGB PSNR, дБ | Прирост над базовой QECNN, дБ |
|---|---:|---:|
| x265 | 24,517 | — |
| Базовая QECNN | 24,738 | 0 |
| Контрольная модель | 24,763 | +0,026 |
| Итоговая модель | **24,840** | **+0,103** |

Точный средний прирост — **0,102553981 дБ**. Относительно x265 выигрыш составляет **0,323252 дБ**. Итоговая модель повысила PSNR на 98 из 100 кадров. [PDF-презентация](output/pdf/qecnn-report.pdf) · [Покадровые метрики](results.json)

## Запуск в Windows

Эксперимент проверен на NVIDIA RTX 4070 Ti с Python 3.11.6, PyTorch 2.3.1, CUDA 11.8 и cuDNN 8.7. Команды для создания окружения в PowerShell. [Сборки PyTorch](https://pytorch.org/get-started/previous-versions/#v231)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.3.1 --index-url https://download.pytorch.org/whl/cu118
.\.venv\Scripts\python.exe -m pip install numpy==1.26.4 opencv-python==4.9.0.80 matplotlib==3.10.3
```

Дважды щёлкните по [train_and_compare.bat](train_and_compare.bat) или запустите его из папки проекта:

```powershell
.\train_and_compare.bat
```

На первом запуске батник обучит обе модели с нуля и проведёт сравнение. Промежуточные файлы появляются в `runs`, а в `runs/final` сохраняются `metrics.json`, `psnr.png` и `examples.png`. При повторном запуске завершённые этапы переиспользуются. Для отдельного эксперимента с нуля выполните команду ниже.

```powershell
.\train_and_compare.bat --fresh
```

Результаты этой команды сохраняются в `runs/repro-*/final`. Правила `.gitignore` исключают новые веса и кэш Python. Чистый повтор на указанном окружении воспроизвёл сохранённые значения PSNR на всех 100 кадрах.

## Данные и метод

| Набор | Оригиналы | Кадры после x265 | Количество |
|---|---|---|---:|
| Обучение и валидация | trainrawyuv/BSD500train.yuv | traincompyuv/BSD500trainc.yuv | 200 |
| Тест | testrawyuv/BSD500val.yuv | testcompyuv/BSD500valc.yuv | 100 |

Кадры 480×320 читаются напрямую из YUV420 и переводятся в RGB. Сначала 160 полных кадров идут на обучение, 40 отводятся для валидации. После выбора весов модель дообучается на всех 200 кадрах. Отдельные 100 кадров используются для измерения PSNR. Начальное значение генераторов случайных чисел равно 42.

- В QECNN добавлен остаточный блок из двух свёрток 3×3 с шагами ядра 2 и 4. Поле зрения выросло с 21×21 до 33×33. У контрольного блока шаги 1 и 1 и столько же параметров.
- Квадратичная ошибка соответствует мере искажения из лекции о сжатии с потерями. Сеть оценивает среднюю поправку к декодированному пикселю по его окружению. При дообучении вес кадра примерно обратно пропорционален его MSE после x265.
- Первичное обучение идёт 25 эпох на фрагментах 64×64. Затем следуют 8 эпох дообучения с валидацией, 8 эпох на всех 200 кадрах с фрагментами 64×64 и 6 эпох на всех 200 кадрах с фрагментами 96×96.
- При восстановлении кадра добавляем зеркальные края по 16 пикселей. Восемь оценок одной сети для поворотов и отражений возвращаются в исходную ориентацию и усредняются. Битовый поток x265 фиксирован. [Исходная QECNN](https://arxiv.org/abs/1709.06734) · [Геометрическое усреднение в EDSR, раздел 4.3](https://openaccess.thecvf.com/content_cvpr_2017_workshops/w12/papers/Lim_Enhanced_Deep_Residual_CVPR_2017_paper.pdf)
